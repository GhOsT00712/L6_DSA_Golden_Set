# L6 DSA Golden Set

A self-contained progress tracker for a curated 120-question Google L6 DSA interview curriculum.

## Features

- 120 categorized questions with LeetCode links
- 30 high-priority L6 questions
- Before-coding clarification prompts
- Production, scale, concurrency, and trade-off follow-ups
- Expandable potential answers
- Status tracking, notes, search, filters, and progress statistics
- Browser-local persistence with import and export
- Responsive dark theme for desktop and mobile

## Run locally

Open `index.html` in a browser. No installation, build process, or server is required.

Progress is stored in the current browser using `localStorage`.
